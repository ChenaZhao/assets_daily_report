1. 原始值

2. 规则分

每个指标先按固定阈值转成 -1 / 0 / +1；不是 z-score、不是回归权重、不是机器学习分数。

3. 模块分

增长、通胀、信用、外需、地产压力在组内等权平均；政策先算货币和财政两个子块，再等权合成。

主状态由增长和通胀闭合；信用、政策、地产、外需主要解释传导和辅助标签。

2026-05：增长 -0.60（偏弱） + 通胀 0.25（温和偏上） => 主状态“放缓”；地产压力 0.60 => 辅助标签“地产压力急性”。外需只解释对冲，不改变主状态闭合。
